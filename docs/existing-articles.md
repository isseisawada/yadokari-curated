## 取り方

- 集計は取得した本文 HTML（`content.rendered`）を BeautifulSoup で数えたもの
- 「2024年以降」と書いた数字は 106本が母数（それ以前は 2014〜2022 年の15本しかない）

## 2. 記事の型（2024年以降）

### タイトル

```
【海外事例】キャッチコピー。国名・種別「物件名」
```

例: 【海外事例】「小さく住む」を、ここまで心地よく。オーストラリア発のトレーラーハウス「Harper」

- `【海外事例】` は 2024-10-11 以降の70本に付く。それ以前は付いていないだけで構成は同じ
- 末尾が「物件名」で終わるのは 70本中50本
- 長さの中央値 49文字

### 本文の構成

```
写真 → via:ドメイン
リード（ビルダー／建築家・国・物件名・ひとことの位置づけ）   ← WP の抜粋はここが自動で入る
<h3> 見出し × 2〜3（中央値2）
   写真 → via → 本文 の繰り返し
締め（暮らし方への一言）
via: 出典URLの列
```

- 70本中66本が**写真から始まる**
- 締めの例:
  - 「小さいから我慢する家ではなく、少ないからこそ深く味わえる暮らし」
  - 「自分の声に静かに耳を傾けながら、“今を生きる”。そんな暮らしのあり方をそっと思い出させてくれる」
- 70本中26本で**日本の暮らしや感覚につなげている**
  （例:「限られた空間を丁寧に使いこなしてきた日本人の営みとも、どこか重なる」）

**仕様の表は1本も無い。** 事実はすべて文中に書く（例: 「全長8メートル、幅2.5メートル、居住面積約20㎡」）。

### 文体

- 常体（「〜だ」「〜だろう」）。です・ます調ではない
- 情緒寄り。「やわらかな」「静かに」「そっと」が多い
- 受賞歴などの事実を1〜2個、文中に入れる
  （例: Black Clay が 2025年の Rising Star Award 最終候補）

## 5. WordPress について分かったこと

- **REST API は外から読める**（`/wp-json/wp/v2/`）。書き込めるかは専用アカウントを作ってから確かめる
- 記事の URL は `/magazine/記事ID/`
- ACF（カスタムフィールド）は入っているが、この記事群では空
- SEO プラグインは、少なくとも Yoast の痕跡は無い。ページには OGP タグ（og:title / og:image 等）が出ている
- 本文まわりのプラグイン: table-of-contents-plus（目次）、master-slider（スライダー）
- 投稿者は複数。121本のうち64本が1人、54本が `YADOKARI`（ID 1）

## 6. 設計に効くこと

- **ソース一覧の出発点**: ArchDaily・Dwell・Dezeen・designboom・Design Milk と
  ビルダーの自社サイト。実際の記事がほぼここから作られている。
  ただし Dezeen は frmg で記事ページがデータセンターの IP から 403 だったので実測が要る
- **下書きの型**: 2 の構成（写真→via→リード→見出し2〜3→締め→出典）をそのまま生成の
  テンプレートにできる。常体・情緒寄り・事実は文中・締めは暮らし方への一言
- **採点の軸の候補**（実際に選ばれている題材から）:
  ビルダー／建築家の作品であること・国がはっきりしていること・写真が4枚以上あること・
  暮らし方の物語があること・日本の読者につなげられること
- **検算**: 価格・面積・寸法・年は元記事にあるものだけ。元資料に無い数字が出たら弾く
