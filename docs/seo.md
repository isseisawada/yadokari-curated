# SEO / AIO（2026-09-29）

狙い: **「トレーラーハウス」で上位に来る**（ユーザー指定）。あわせて「タイニーハウス」「小屋」。
AIO は、Google の AI による概要や ChatGPT・Perplexity などの AI の回答に引用されること。

**上位表示の保証はできない。** 順位は競合・被リンク・サイト全体の評価・更新頻度で決まる。
ここでやっているのは、記事とサイトの側で打てる手を漏れなく打つこと。

## 1. 採点（何を記事にするか）

- 軸 `seo`（重み 0.10）を追加。トレーラー系（車輪付きタイニーハウス・トレーラー・キャラバン）100、
  小屋 60、そのほか 40〜50。**同じ出来ならトレーラー系が上に来る**
- 重みの配分: design 0.22・story 0.22・smallness 0.13・photos 0.13・japan 0.10・seo 0.10・
  facts 0.05・freshness 0.05

## 2. 記事（下書きで自動）

| 項目 | 中身 |
|---|---|
| タグ | **すべてに「タイニーハウス」「小屋」**。トレーラー系は**「トレーラーハウス」も**。WP のタグ ID は固定（274・162・323） |
| 主キーワード | 種別で決める。トレーラー系 → トレーラーハウス / 小屋・ツリーハウス → 小屋 / そのほか → タイニーハウス |
| タイトル | 既存の型（【海外事例】キャッチ。国・種別「物件名」）の「種別」に主キーワードを入れる |
| リード1文目 | 「〈物件名〉は、〈国〉の〈ビルダー〉が手がけた〈主キーワード〉だ。」の定義の文。**AI の要約・検索の抜粋に引かれやすい** |
| 見出し | 少なくとも1つに主キーワード |
| 説明文 | 80〜120字。WP の抜粋に入れる（テーマは抜粋を meta description と og:description に使っている） |
| データ欄 | 「〈物件名〉のデータ」: 物件名・ビルダー・設計・国・地域・面積・サイズ・価格・完成年。**元記事に無い数字を含む値は出さない** |
| よくある質問 | 2〜3問。**答えが元記事にあるものだけ**。数字は検算にかける |
| 写真の alt | 空にしない。「〈種別〉「〈物件名〉」の写真 n/N」 |
| 内部リンク | 最後に「関連：トレーラーハウスの記事一覧／タイニーハウスの記事一覧／小屋の記事一覧」 |

**トレーラーでない物件に「トレーラーハウス」と書かない。** 物件に当てはまらない語を詰め込むのは
検索エンジンのスパムに関する方針に触れ、サイト全体の評価を下げうる。タグの「トレーラーハウス」も
トレーラー系だけに付ける（「タイニーハウス」「小屋」は指定どおり全記事）。

下書き画面の **SEO / AIO** 欄で、12項目（タイトル・説明文の長さと語・リード1文目・見出し・
本文での出現回数・必須タグ・alt・文字数・データ欄・内部リンク）を毎回測り直す。

## 3. サイト（WP プラグイン。**入れるかはユーザー判断**）

2026-09-29 時点の yadokari.net は**構造化データ（JSON-LD）を1つも出していない**。
`wordpress-plugin/yadokari-curated-seo.php` を `wp-content/mu-plugins/` に置くと、全記事に次が出る:

- `Article`（見出し・説明・公開日・更新日・画像・著者・発行者・キーワード・カテゴリ）
- `BreadcrumbList`（トップ › カテゴリ › 記事）
- yadokari-curated から送った記事は `about`（物件名・種別・所在地・面積）と `mentions`（ビルダー・設計者）

入れたら `config.yaml` の `seo.send_facts_meta: true` にする（物件の事実を post meta `yc_facts` で送る）。
**本番の前にステージングで確認**し、Google のリッチリザルト テストで読めることを確かめる。

## 4. 記事の外でやると効くこと（システムの外・参考）

- 「トレーラーハウス」の**まとめページ**（入門・価格・法規・事例一覧）を1本作り、個別記事から
  内部リンクを集める。いまの「トレーラーハウスの記事一覧」はタグページ（316本）で、まとめとしては弱い
- 既存の「トレーラーハウス入門書」（資料ダウンロード）への導線を記事末に置く
- Search Console で「トレーラーハウス」の表示回数・順位・クリック率を毎週見る
  （週次レポートに入れられる。Search Console の API 権限が要る）
